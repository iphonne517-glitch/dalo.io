# 🪖 حاسبة التقاعد والمستحقات العسكرية للأفراد

صفحة HTML واحدة (بدون مكتبات أو خادم) تحسب المعاش والمكافآت وتحلل الفجوة المالية بعد التقاعد.

**اعداد وتصميم: ابو ساهر الشافعي**

## المميزات
- سلم رواتب الأفراد (جندي ← رئيس رقباء) بدرجات 1–15 مع العلاوة الدورية، وتعديل الراتب يدوياً.
- مدة الخدمة بالتاريخ الهجري مع الخدمة الإضافية (العمليات الحربية / المناطق النائية).
- حالات إنهاء الخدمة: بلوغ السن، التقاعد المبكر، العجز أو الاستشهاد في العمليات الحربية، العجز الصحي.
- مكافأة نهاية الخدمة، تسوية الدفعة الواحدة، وبدل الإجازات (حد أقصى 180 يوماً).
- البدلات والعلاوات أثناء الخدمة، وحسم المؤسسة العامة للتقاعد.
- مقارنة بصرية بين صافي الراتب والمعاش، ووضع ليلي/نهاري، وطباعة التقرير.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub وارفع كل ملفات هذا المجلد (بما فيها المجلد المخفي `.github`).
2. من **Settings ← Pages** اختر **Source: GitHub Actions**.
3. بعد أول `push` على فرع `main` يُنشر الموقع تلقائياً على:
   `https://USERNAME.github.io/REPO/`

بديل بدون Actions: **Settings ← Pages ← Deploy from a branch ← main / (root)**، ويمكنك حينها حذف مجلد `.github`.

## التشغيل محلياً
افتح `index.html` في أي متصفح.

## تنبيه
الحاسبة استرشادية، والمرجع النهائي هو الأنظمة والتعاميم الرسمية.
